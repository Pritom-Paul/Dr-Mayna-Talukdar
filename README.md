# Dr. Mayna Talukdar Academic Portfolio

A bilingual English/Bengali static academic portfolio for Dr. Mayna Talukdar, Professor of Sanskrit at the University of Dhaka.

## Commands

```sh
npm run dev
npm run build
npm run preview
```

The production site is configured for a root-based Vercel deployment. Astro is
static by default, so Vercel can detect the framework and build it without an
adapter. Import the repository into Vercel, keep the project root at the
repository root, and use the detected `npm run build` command with `dist` as
the output directory.

## Content policy

The detailed CV is the authority for publication titles and citation wording. External links appear only where an exact reliable source was found. Unknown links remain empty, and sensitive personal details from the CV are excluded from the public site.

See [planner.md](./planner.md), [docs/CONTENT_MATRIX.md](./docs/CONTENT_MATRIX.md), and [docs/IMPLEMENTATION_CHECKLIST.md](./docs/IMPLEMENTATION_CHECKLIST.md) for the implementation record and deployment checklist.
